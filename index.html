Three keystrokes, any app

Pressto reads the same description of the screen that VoiceOver uses, so it works in apps that were never designed for it.

Open

⇧⌘H opens the palette over the window you are using, on the right display.

Type

A few letters are enough: initials, part of a word, part of a web address. Results rank as you type.

Press

↵ presses the button for real — even one hidden behind a dialog or scrolled out of view.

Questions

Why does Pressto ask for Accessibility access?

That permission is how any app can see and press another app's buttons. Pressto uses it only for that, on your Mac: it collects nothing and makes no network requests.

Why isn't it on the Mac App Store?

The App Store requires a sandbox that forbids pressing other apps' buttons — which is the whole point. Pressto will ship as a signed, notarized download instead, like most keyboard tools for the Mac.

Can I still point at things the old way?

Yes. Pressto keeps hint labels (⇧⌘J), a keyboard grid (⇧⌘K) and free cursor movement (⇧⌘L) for anything that has no name.

Where does it come from?

Pressto is built on Scoot by Michael Russo, an open-source keyboard cursor tool, under the BSD licence. The search is new; fixes that help Scoot too are offered back upstream.
